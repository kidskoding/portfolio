Most people's first minute in Neovim is figuring out how to quit. After this post yours is: fuzzy-open a file, change an argument without selecting it, rename across the project, accept or reject an agent diff, hit a breakpoint, commit. No mouse.

**Agents write more of the code now. Your job is the pass after — read, navigate, review, correct — and modal editing in a terminal is built for that.** Neovim is not better AI than Cursor; [Claude Code](https://docs.anthropic.com/en/docs/claude-code) is a CLI either way. [claudecode.nvim](https://github.com/coder/claudecode.nvim) just puts the diffs in your buffers. I still open VS Code for full-grade IDE work. Keep it installed.

I bounced off Neovim in 2022. What stuck was a complete editor first, keys only when an edit needed them. That build is below; [nvimforge](https://github.com/kidskoding/nvimforge) is the same files if you want a reference.

Tools and platform installs: [appendix](#appendix-installing-everything). Already have a config? [Park it](#if-you-already-have-a-neovim-config).

## The edit you actually make

Agent proposes this. Easy to accept, wrong for a pure sum:

```diff
 def total_value(items: list[Item]) -> float:
-    return sum(item.price * item.quantity for item in items)
+    total = 0.0
+    for item in items:
+        total += item.price * item.quantity * 1.08  # tax??
+    return round(total, 2)
```

In Neovim you don't paint a selection — you compose. `c`/`d`/`y` + a target (`iw` word, `i(` inside parens, `af` around function). Cursor on the function, `daf` deletes it, you put the one-liner back, move on. Same grammar on a one-char typo with `ciw`. You'll hit those keys in the tour after setup.

### community.lua + overrides

[AstroCommunity](https://github.com/AstroNvim/astrocommunity) = one import per feature (plugin + deps + keys). Paste this whole file as `lua/community.lua` (matches nvimforge). Python uses [ty](https://docs.astral.sh/ty/) + [Ruff](https://docs.astral.sh/ruff/) — don't also enable plain `pack.python`.

```lua
-- lua/community.lua
-- AstroCommunity: ready-made plugin setups, turned on with one `import` line each
-- browse everything available here: https://github.com/AstroNvim/astrocommunity

---@type LazySpec
return {
  "AstroNvim/astrocommunity",
  { import = "astrocommunity.pack.lua" }, -- helps when editing these config files
  { import = "astrocommunity.bars-and-lines.lualine-nvim" }, -- the status bar
  { import = "astrocommunity.bars-and-lines.bufferline-nvim" }, -- the tabs

  -- languages (uncomment the languages you use!)
  -- check out all available language extension packs here: https://github.com/AstroNvim/astrocommunity/tree/main/lua/astrocommunity/pack
  { import = "astrocommunity.pack.python.base" }, -- Python syntax, the debugger, and a virtualenv picker
  { import = "astrocommunity.pack.python.ty" }, -- ty: type checking, go-to-definition, and hover docs
  { import = "astrocommunity.pack.python.ruff" }, -- Ruff: linting and formatting
  -- { import = "astrocommunity.pack.typescript" },
  -- { import = "astrocommunity.pack.rust" },

  { import = "astrocommunity.ai.claudecode-nvim" },

  { import = "astrocommunity.recipes.auto-session-restore" },
}
```

Already included by AstroNvim: Neo-tree, fuzzy finder, DAP debugger (`F5`/`F9`/`F10`), terminal (`F7`), Git signs. You still need `lazygit` on `PATH` and `claude` installed from its docs. `:Mason` after restart watches language tools land.

## Tour

```python
# inventory/models.py
from dataclasses import dataclass

@dataclass
class Item:
    name: str
    price: float
    quantity: int

def total_value(items: list[Item]) -> float:
    return sum(item.price * item.quantity for item in items)
```

```python
# inventory/report.py
from models import Item, total_value

items = [
    Item("keyboard", 49.99, 3),
    Item("mouse", 19.99, 5),
]

print(f"Inventory value: {total_value(items):.2f}")
```

```sh
cd inventory && git init && git add . && git commit -m "Initial inventory" && nvim
```

Space is leader (`<Leader>`). Press Space alone → [which-key](https://github.com/folke/which-key.nvim). Forget a key? Read the menu. Mac: Ctrl stays Ctrl, not Cmd.

| Do | Keys |
|---|---|
| Find file | `<Leader>ff` then `rep` → `report.py` |
| Project search | `<Leader>fw` |
| File tree | `<Leader>e` |
| Insert / Normal | `i` / `Esc` |
| Change word under cursor | `ciw` (then type, `Esc`, `Ctrl+S`) |
| Undo | `u` |
| Full diagnostic | `gl` |
| Hover / go to def | `K` / `gd` (`Ctrl+O` back) |
| Rename symbol | `<Leader>lr` … then `:wa` (Neovim won't auto-save other buffers) |
| Claude Code panel | `<Leader>Ac` · send selection `<Leader>As` · accept `<Leader>Aa` · reject `<Leader>Ad` |
| Terminal / debug / Git | `F7` · `F9`/`F5`/`F10` · `<Leader>gg` (Space stage, `c` commit, `q` quit) |
| Quit | `:qa` |

Composition: `c`/`d`/`y` + `iw` / `i(` / `i"` / `af`. Line ops: `dd`, `p`. Next function: `]f`. Repeat last change: `.`

## Later

`<Leader>fk` searches maps; `<Leader>fh` searches help. Grow `astrocore` from friction, not plugin FOMO:

```lua
-- lua/plugins/astrocore.lua (example)
return {
  "AstroNvim/astrocore",
  opts = {
    options = {
      opt = {
        cmdheight = 1,
        relativenumber = false,
      },
    },
    mappings = {
      n = {
        ["<Leader>W"] = { "<Cmd>wall<CR>", desc = "Save all buffers" },
      },
    },
  },
}
```

Want the wiring without AstroNvim? [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim). Staying on AstroNvim for years is fine.

Keep Cursor or VS Code when they win. Use Neovim for the pass after the agent. That pass is more of the job every year; the editor that's fastest there earns the permanent window.

## Appendix: installing everything

### What you need

| Tool | Why | Check |
|---|---|---|
| Neovim 0.11+ | Editor (AstroNvim v6 min; written against 0.12) | `nvim --version` |
| Git | Config and plugins | `git --version` |
| Node.js | Most language servers | `node --version` |
| C compiler | Tree-sitter parsers | `gcc --version` or `clang --version` |
| tree-sitter CLI | Parsers | `tree-sitter --version` |
| ripgrep | Project search | `rg --version` |
| fd | File search | `fd --version` |
| Nerd Font | Icons | [Fonts](#fonts-and-icons) |
| lazygit | Git UI | `lazygit --version` |
| Claude Code | Agent | `claude --version` |
| Python 3 | Examples | `python3 --version` |
| Neovide | Optional GUI | `neovide --version` |

Linux clipboard: `wl-clipboard` or `xclip`. nvimforge's flake also pulls ripgrep, fd, tree-sitter, lazygit, Node, and a C compiler.

### Installing the tools

From Neovim's [install guide](https://github.com/neovim/neovim/blob/master/INSTALL.md); Claude Code from [its docs](https://docs.anthropic.com/en/docs/claude-code):

```sh
# macOS
xcode-select --install
brew install neovim git node ripgrep fd lazygit
brew install --cask font-jetbrains-mono-nerd-font

# Windows (PowerShell)
winget install Neovim.Neovim Git.Git OpenJS.NodeJS.LTS \
  BurntSushi.ripgrep.MSVC sharkdp.fd JesseDuffield.lazygit

# Arch
sudo pacman -S neovim git nodejs npm base-devel \
  ripgrep fd tree-sitter-cli lazygit

# Debian / Ubuntu (Neovim from tarball below)
sudo apt install git nodejs npm build-essential ripgrep fd-find unzip

# Other Linux x86_64
curl -LO \
  https://github.com/neovim/neovim/releases/latest/download/nvim-linux-x86_64.tar.gz
sudo tar -C /opt -xzf nvim-linux-x86_64.tar.gz
export PATH="$PATH:/opt/nvim-linux-x86_64/bin"
```

If `nvim --version` is older than 0.11, use the tarball and put the `export` in your shell rc. Debian/Ubuntu: `fd` is `fdfind`. Windows needs a C compiler (e.g. VS Build Tools). Missing tree-sitter CLI: drop the guard in template `lua/plugins/mason.lua` (`tree-sitter-cli` is listed).

### Fonts and icons

[Nerd Font](https://www.nerdfonts.com/font-downloads) in the terminal, or `icons_enabled = false` in `lua/lazy_setup.lua`.

### Neovide

[Install](https://neovide.dev/installation.html), then `neovide` uses this config. GUI font example in `lua/polish.lua`: `vim.o.guifont = "JetBrainsMono Nerd Font:h14"`. Nix: `nix run .#neovide` from nvimforge.

### Windows template path

```powershell
git clone --depth 1 https://github.com/AstroNvim/template $env:LOCALAPPDATA\nvim
Remove-Item $env:LOCALAPPDATA\nvim\.git -Recurse -Force
nvim
code $env:LOCALAPPDATA\nvim
```

### When it doesn't work

- Boxes for icons → Nerd Font or `icons_enabled = false`
- No highlights → C compiler / tree-sitter CLI on `PATH`
- LSP dead → `:Mason`, language toolchain installed
- No `<Leader>fw` → install ripgrep
- Config ignored → still have `if true then return {} end`
- Stale red errors → `:w` / `:LspRestart`
- No Claude panel → `claude` works in a shell
- Nuclear → `:checkhealth`, or `nvim --clean`

### If you already have a Neovim config

```sh
mv ~/.config/nvim ~/.config/nvim.bak
mv ~/.local/share/nvim ~/.local/share/nvim.bak
mv ~/.local/state/nvim ~/.local/state/nvim.bak
mv ~/.cache/nvim ~/.cache/nvim.bak
```

Windows: `%LOCALAPPDATA%\nvim` and `%LOCALAPPDATA%\nvim-data`.

### Undoing it

```sh
rm -rf ~/.config/nvim \
  ~/.local/share/nvim \
  ~/.local/state/nvim \
  ~/.cache/nvim
mv ~/.config/nvim.bak ~/.config/nvim
mv ~/.local/share/nvim.bak ~/.local/share/nvim
mv ~/.local/state/nvim.bak ~/.local/state/nvim
mv ~/.cache/nvim.bak ~/.cache/nvim
```

### Nix

`nix shell nixpkgs#neovim`; on NixOS add packages to `environment.systemPackages`. Mason + NixOS often needs `programs.nix-ld` or nixpkgs tools instead. nvimforge's `flake.nix` runs this config beside an existing Neovim install.
